# PS5 Linux Loader — 13.60 port status

## Goal

Extend ps5-linux-loader toward PS5 firmware 13.60 while preserving the existing 3.00–7.61 Linux boot paths.

## Implemented

- Firmware detection accepts 0x1360 (13.60).
- A dedicated off_1360 firmware profile is registered.
- The verified public kernel profile value VMSPACE_VM_PMAP = 0x2e8 is preserved.
- The loader validates HV/backend capability before Linux image mappings or resume preparation.
- Firmware backends are selected through a common descriptor interface.
- 13.60 has a dedicated backend integration point and a fail-closed implementation.
- Missing 13.60 profile capabilities can be reported independently from the raw offset structure.
- A static regression test verifies the 13.60 profile and backend gate.

## Phase 3 status

The loader-side integration framework for a 13.60 HV implementation is now complete.

The backend contract is represented by:

- hv_backend_descriptor
- hv_backend_prepare_fn
- firmware-specific required-profile capability bits
- hv_backend_missing_requirements()
- hv_profile_validate()

This separates:

1. Firmware profile data.
2. Backend capability validation.
3. Firmware-specific HV preparation.

The existing 3.00–7.61 implementations remain unchanged behind the dispatcher.

### 13.60 limitation

A public, source-available and independently verifiable 13.60 HV implementation is still required before the available flag can be enabled and Linux boot can be attempted.

The current public PS5 Linux loader still documents support only through 7.61. Community sources report a 13.60 HV PoC, but no official public source implementation suitable for direct integration is available in this repository.

Therefore the 13.60 backend deliberately remains fail-closed. No VM-exit handler, ROP chain, hypervisor write primitive, or resume payload has been guessed or synthesized.

## Validation

Run:

    make test

or directly:

    python3 tests/test_13_60_profile.py

The test is static and does not claim that a 13.60 console can boot Linux.

## Next step

When a public 13.60 HV implementation is available, integration should be limited to:

1. Add its firmware-specific payload/backend source.
2. Populate only the offsets it demonstrably consumes.
3. Set backend_1360.available = true only after profile validation and console testing pass.
4. Keep the existing dispatcher and Linux resume flow unchanged.
