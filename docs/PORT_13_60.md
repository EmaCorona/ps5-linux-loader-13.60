# PS5 Linux Loader — 13.60 port status

## Goal

Extend ps5-linux-loader toward PS5 firmware 13.60 while preserving the existing 3.00–7.61 Linux boot paths.

## Implemented in this phase

- Firmware detection accepts 0x1360 (13.60).
- A dedicated off_1360 firmware profile is registered.
- The profile contains the verified VMSPACE_VM_PMAP = 0x2e8 value used by the loader's page-table discovery.
- The loader checks that the selected firmware has a complete HV profile before touching Linux image mappings or preparing resume.
- 13.60 fails closed with an explicit diagnostic instead of falling through to an older HV implementation.

## Intentionally not implemented

The existing Linux boot flow requires a firmware-specific Hypervisor defeat/resume backend. The 6.50–7.61 implementation in source/hv_defeat_0607.c cannot safely be reused for 13.60 merely by changing offsets.

No 13.60 HV payload, ROP chain, VM-exit handler, or resume trigger has been invented here. Such code must be based on a publicly available and independently verifiable 13.60 HV implementation.

## Verified kernel profile source

The 13.60 values were cross-checked against:

- ps5-payload-dev/sdk, crt/kernel.c, firmware case 0x13600000
- soniciso1/relapse, offsets/13.60.js, for the 13.60 kernel-exploitation profile

The SDK reports the 13.60 kernel layout with:

- text base = data base - 0x0CC0000
- vmspace root pmap offset = 0x2e8
- allproc = data base + 0x28C9E80
- security flags = data base + 0x0D9C064
- rootvnode = data base + 0x314B510

Only the pmap offset is required by the current loader initialization stage, so only that field is populated in off_1360.

## Next implementation phase

1. Define a dedicated 13.60 HV backend interface.
2. Integrate a public, verified 13.60 HV implementation.
3. Populate and validate all resume/VM-exit-specific offsets required by that backend.
4. Add compile-time and runtime validation for the complete 13.60 profile.
5. Test the loader on 13.60 before changing the PS5 Linux image/Bazzite integration.

Until step 2 exists, this branch is **not a working 13.60 Linux bootloader**.
